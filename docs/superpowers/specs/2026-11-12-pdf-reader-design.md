# PDF 阅读器

用户要求：项目 `pdf-reader`，包名 `com.jy.pdf.read.io`，只阅读 PDF。目标 Ocean 4 Turbo 2025，Android 10/API29，arm64-v8a，App 堆 128 MiB。

- 打开 PDF：应用内系统选择器，文件管理器“用其他应用打开”的 PDF ACTION_VIEW。支持 content URI 临时授权，不要求系统签名或 root。
- 单页渲染，裁切框按比例应用到整份文档（用户已选择）。不修改原 PDF；可重置。
- 裁切后宽度适配可见区域作为最小缩放；缩放 1–4 倍。双指和按钮缩放，单指横纵拖动，有横纵滚动条。
- scanCode 115 上翻，114 下翻；回退兼容音量键和 PAGE_UP/DOWN。按键始终拦截阅读时的这些键，不改变音量，不改变横向位置。
- 每次按下纵向移动约 80% 可见高度；已经在顶/底时新的按下才翻上一/下一 PDF 页。上一页从底部继续，下一页从顶部继续。长按可重复滚动，但不连跨页。
- 以内容 MD5 为 ID，用原子 JSON 存页码、PDF 页内坐标、缩放、全书裁切。重新打开、改名、从其他 App 打开仍恢复。后台/退出/切文档立即保存，滚动后短延迟保存。
- 原生 Java + Android PdfRenderer，无 JNI 和第三方运行库。可见区域 512px 分块，缓存按堆大小限制，避免放大整页的巨大 Bitmap。应用 APK 通用，支持目标 arm64 和 32 位系统。
- 高对比黑白界面，不做翻页动画。顶部悬浮层仅返回与文件名，底部悬浮层放页码/上一下一页与裁切缩放控件。两层覆盖 PDF，不占版面；单击 PDF 任意位置同时隐藏/显示，拖动缩放不切换。
- 系统选择器为首选；Android10 提供可选设备文件浏览作为定制系统的后备入口，只列文件夹与 PDF。

取舍：复用网盘项目会引入云端业务和大量依赖；采用独立原生项目。整页高分辨率渲染更简单但在 128MiB 堆易超限，采用预览加可见分块。
文件导入为内部副本，以支持不可 seek 的 content provider 并保证后续进度恢复；明确显示“移除本地副本”且不删除来源文件。暂不支持密码 PDF、批注、OCR、文字重排。
